# How to Make Really Annoying Web Sites-vurdering

I den skolen får den **9,6/10 irriterende-webmasterpoeng**.

Den har akkurat riktig energi: «lesbarhet er et forslag», graffiti som nesten spiser sin egen tekst, `<` som både kode og sabotasje, og nok visuell støy til at en 1999-webmaster umiddelbart ville tenkt: *Dette trenger bare en blinkende hit-counter og MIDI.*

For full **10/10 _How to Make Really Annoying Web Sites_-ånd** mangler bare:

- `<marquee>` rundt hele logoen
- `<blink>` på én tilfeldig bokstav
- 14 px Comic Sans et sted den absolutt ikke hører hjemme
- musepeker med gnistspor
- «BEST VIEWED IN NETSCAPE 4.7 AT 800×600»
- en popup som spør om du virkelig vil lukke popupen
- bakgrunns-MIDI som starter automatisk
- `UNDER CONSTRUCTION`-GIF uten at siden noensinne blir ferdig
- visitor counter: `0000042`
- høyreklikk deaktivert med JavaScript fordi «SOURCE CODE PROTECTED»

Og selvfølgelig HTML-en:

```html
<marquee scrollamount="17">
  <blink>UNGET BLOD BLC&lt;SWAN</blink>
</marquee>
```

Validator: **47 errors, 13 warnings.**

Webmaster: **«Works on my machine.»**
